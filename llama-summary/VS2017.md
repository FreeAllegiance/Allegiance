PURPOSE: tiny file (10 lines), shown in full rather than summarized.

    Get SteamCMD from: https://steamcdn-a.akamaihd.net/client/installer/steamcmd.zip
    Unzip it to C:\Steam
    run c:\Steam\SteamCMD
    Run these steamCMDs from inside SteamCMD:
        login anonymous
        force_install_dir c:\Allegiance\Server
        app_update 730810
    Go to C:\Allegiance\Server
    Follow instructions in the readme.
    The batch files are looking for files in these paths, so it would be easiest not to modify them.

## `VS2017/lobby config file.txt`

PURPOSE: The file `Allegiance.cfg` is a configuration file used by the Allegiance lobby service to manage server connections and core configurations.

KEY PARTS:
- `[Lobby]`: Section defining the number of servers allowed and their IP addresses.
- `[Cores]`: Lists available cores with their names and versions.
- `[OfficialCores]`: Indicates which cores are considered official or recommended.
- `[OfficialServers]`: Lists official server IP addresses.

CONNECTS TO: The Allegiance lobby service, which uses this configuration to manage server connections and core availability.

NOTES:
- There is a commented-out section for disabling `Betasrv`.
- Some servers have comments indicating their creators or purposes (e.g., "FAZDev - pkk", "Weedman's test server").
- The file includes both enabled and disabled server entries, allowing administrators to easily enable or disable specific servers.
